# Travel Finds — EN/ES travel deals

Статический сайт с подборками дешёвых перелётов, отелей и city-break'ов.
Партнёрские ссылки TravelPayouts, без цен и наличия в реальном времени.

- Live: https://travel-finds-usa.pages.dev/travel-finds/
- EN: `index.html`, ES: `es.html`
- Гайды: `blog/*.html`
- Стили/скрипты: `assets/`
- `sitemap.xml`, `robots.txt`, `.nojekyll` — для GitHub Pages.

## Деплой

GitHub Pages из ветки `main` (корень). Пуш в `main` → пересборка.

## Правовое

Партнёрские ссылки раскрываются на странице. Цены/доступность меняются —
перед покупкой проверяйте у провайдера. Это не финансовая рекомендация.
